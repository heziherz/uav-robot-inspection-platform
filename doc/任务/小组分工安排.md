# 无人机-机器狗空地协同巡检集成平台 —— 小组分工安排

> **项目依据**：《企业应用开发实践》指导说明书 · 六、小组分工要求（每组 4-6 人，要求分工均衡，每个人明确承担核心任务）。

## 一、分工明细

| 序号 | 角色分工 | 主要职责 | 具体负责人 |
| :---: | :--- | :--- | :---: |
| 1 | 架构与设计负责人 | 负责需求分析、总体架构设计、组件技术选型 | |
| 2 | 中间件部署运维负责人 | Hadoop、MongoDB、Kafka/RocketMQ、ES、Nginx 集群部署、配置调优、排错 | |
| 3 | 后端业务开发负责人 | 业务服务开发、消息消费、存储读写接口开发 | |
| 4 | 仿真与数据处理负责人 | 无人机、机器狗设备仿真模块，数据处理逻辑 | |
| 5 | 前端可视化负责人 | Web 界面、设备地图展示、告警可视化 | |
| 6 | 测试与文档负责人 | 测试用例编写、测试报告、汇总全套文档 | |

## 二、填写说明

1. 请在“具体负责人”列填写小组成员姓名；如分工交叉承担，可注明主要 / 协助。
2. 要求分工均衡，禁止部分组员只做文档、部分组员只做编码。
3. 答辩及个人自我总结报告需明确说明每个人实际完成的工作内容。
4. 参考职责对应关系：中间件部署运维负责人覆盖 **Hadoop HDFS、MongoDB、RocketMQ/Kafka、Elasticsearch、Nginx** 五类强制组件（可用 Docker 单机容器模拟集群部署）。
