### 3.3 5.3 关键问题与解决方案（素材很足，直接整理）

本项目实际解决过的问题，按"**现象 → 排查 → 原因 → 解决**"四段式整理：

| # | 问题现象 | 根因 | 解决 |
| :--- | :--- | :--- | :--- |
| 1 | Spring Boot 4 下 MongoDB 连不上，一直连 `localhost` | **Boot 4 重命名了配置前缀**：`spring.data.mongodb.*` → `spring.mongodb.*`，旧名静默回退默认值 | 改用新前缀 + 环境变量 `SPRING_MONGODB_URI` |
| 2 | Jackson 3 换包名，`ObjectMapper` 找不到 | Boot 4 用 **Jackson 3**，包名 `com.fasterxml.jackson` → `tools.jackson` | 改用 `tools.jackson.databind.json.JsonMapper` |
| 3 | 容器内 Producer 连不上 Kafka | Kafka **广告监听器**返回容器内地址，宿主机不可达（"门牌号"问题） | 配置**双 listener**：`PLAINTEXT://kafka:9092` + `EXTERNAL://localhost:19092` |
| 4 | 时序集合写入报错：`'eventTime' must be a valid BSON UTC datetime` | 时序集合的 `timeField` **必须是 Date 类型**，不能是 long | 写入前 `new Date(msg.eventTime())` |
| 5 | HDFS 上传路径异常：`/app/sim-files/D:\school\...` | Linux 容器中 `Paths.get()` **不认 Windows 反斜杠**，把整串当文件名 | 当时用正则剥前缀绕过；**后经架构改造根治**——影像改由设备自己上传，消息中只传 `storageRef`，平台不再接触设备本地路径 |
| 6 | Spring Boot 4 中 `spring-boot-starter-web` 不存在 | Boot 4 模块化重命名 | 改用 `spring-boot-starter-webmvc` |
| 7 | 批量处置告警时，勾选 3 条只有 1 条真正执行 | taskId 用毫秒时间戳，同毫秒内**编号重复** → msgId 重复 → 被设备侧幂等保护**静默丢弃** | 改用 MongoDB **原子计数器**生成编号 |
| 8 | ES 未按 `geo_point` 建索引 | 只有动态映射，**没有 index template** | （待补）定义 index template |
| 9 | 容器 `Recreate` 未生效 | 普通 `--build` 不重建容器 | 用 `--build --force-recreate` |
| 10 | 页面白屏 `can't access property "alarmId", c is null` | 接口一次返回 1600+ 条导致响应过大 + `useEffect` 依赖写法问题 | 改**服务端分页** + 修正依赖 |

> 第 7、8 条是本项目**独有**的发现（一般教程里没有），答辩时讲这两条最能体现真实排错能力。
